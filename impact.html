    Your data

    Everything Heal knows is stored in this browser, on this device only. If you clear your browser data or switch to another browser or device, you'll start afresh, so export a copy if you'd like to keep it.

    Using Heal on more than one device? Export your data on one and import it on the other: you can combine it with what's already there. A spreadsheet copy is for reading or charting, and can't be imported.

    Import this file?

    Combining keeps everything here and adds what's new from the file, apart from check-ins for days that already have one. Replacing can't be undone, so export your data first if you might want it back.
